# ai-soc-analyst-assistant
AI-powered SOC Analyst Assistant for threat analysis, suspicious email detection, and security incident reporting.
## About Project

AI SOC Analyst Assistant is a cybersecurity project designed to help security analysts analyze suspicious activities and generate security reports.

## Features

- Email threat analysis
- Risk level classification
- Indicator of Compromise (IOC) extraction
- Security incident report generation
- SOC workflow assistance

## Technologies

- Python
- React
- AI
- Database
